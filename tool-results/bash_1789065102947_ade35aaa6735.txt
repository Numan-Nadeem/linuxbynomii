(normal) Setgid
(normal) If enabled on directory, all file inside that directory will have group of the directory as group value.

(normal) Sticky Bit
(normal) Prevent deletion of file except from owner/root user
(normal) Chmod o+t -> set sticky bit
(normal) Umask
(normal) Used to set default permissions for new created directories
(normal) Files will have same permissions as directories excluding the execute permissions

(normal) Default umask is stored in /etc/profile file
